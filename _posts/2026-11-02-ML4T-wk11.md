# 3-5 Reinforcement learning

## 1. Overview

Reinforcement learners create policies that provide specific direction on which action to take.

## 2. The RL Problem
### 2.1. What is the RL problem?

Reinforcement Learning (RL) describes a learning problem, not a specific algorithm or solution. 

Just as linear regression is one method for solving a supervised regression problem, there are many algorithms that can solve a reinforcement learning problem.

The central idea of RL is:

**An agent learns how to make decisions by interacting with an environment and receiving rewards or penalties based on its actions.**

<img width="574" height="390" alt="image" src="https://github.com/user-attachments/assets/7229d27e-d43b-4e47-965e-f64330cca1d5" />

For example, imagine a robot learning how to navigate a room. It needs to:

1. Observe its surroundings.
2. Decide what action to take.
3. Perform the action.
4. Receive feedback (reward or penalty).
5. Observe the new situation and decide what to do next.

This process is called the Sense–Think–Act cycle.

### 2.2 The five key components of RL
<img width="791" height="300" alt="image" src="https://github.com/user-attachments/assets/4fe5fa9f-f448-4683-9a87-0e90e4e56c09" />

`Step 1: Observe the environment (State, s)`

The robot first observes its environment.

The information it receives is represented by the state (s).

For example:
- The robot is currently in front of a wall.
- There is an open path to the right.
- Its destination is straight ahead.
All this information helps describe the robot's current state.

`Step 2: Decide what to do (Policy, π)`

The robot needs a strategy to decide which action to take.

This strategy is called the policy (π).


For example:
- If there is a wall ahead, turn right.
- If the path is clear, move forward.
  
**The policy is essentially the robot's decision-making strategy**.

`Step 3: Take an action (a)`

Based on the policy, the robot performs an action.

Examples:
- Move forward.
- Turn left.
- Turn right.
- Stop.

The action can change the environment.

The question is **how do we arrive at this policy?** This whole puzzle is missing a piece and that's the thing that helps us find pi.
And part of that piece is called r which is the **reward**. 

`Step 4: Receive a reward (r)`

After taking an action, the robot receives feedback called a reward (r).

The reward tells the robot whether its behavior was desirable.

For example:
<img width="792" height="185" alt="image" src="https://github.com/user-attachments/assets/9de72940-df05-42d2-862e-9c9a2b3b65f0" />

The reward provides feedback that helps the robot learn which actions are beneficial.

**Important**: The goal of RL is not simply to maximize the reward from one action. It is to maximize the total accumulated reward over time.

`Step 5: Environment changes (Transition, T)`

After the robot takes an action, the environment transitions to a new state.

This process is described by the transition function (T).
<img width="721" height="175" alt="image" src="https://github.com/user-attachments/assets/3a41dcd2-29ca-47a9-a805-0deb06ade88e" />

For example:

The robot is facing a wall (current state), decides to turn right (action), and now faces an open path (new state).

In real-world problems, transitions may be stochastic, meaning the same action can sometimes lead to different outcomes.

### 2.3 How does the robot learn the best policy?

This is the most important question in reinforcement learning.

Initially, the robot may not know which actions are best. It needs to learn from its interactions with the environment.

Over time, it uses the information it collects, including:
- States it has encountered.
- Actions it has taken.
- Rewards it has received.
- Outcomes of its actions.
  
An RL algorithm uses this experience to improve the policy.

The ultimate objective is:

`Maximize cumulative reward over time`

For example, the robot should learn to reach its destination efficiently rather than repeatedly hitting walls or taking unnecessary steps.

The key distinction:
- The RL problem defines what needs to be solved.
- The RL algorithm describes how to solve it.
- The policy is the learned strategy used to select actions.

# 03-06 Q-Learning
## 1. Overview
### 1.1 What is Q-Learning?

- Q-Learning is a model-free reinforcement learning algorithm.
- It does not require knowing the transition function (T) or reward function (R).
- Instead, it learns through interactions with the environment.

### 2. How does it work?
- Builds a Q-table to store utility values (Q-values) for state-action pairs.
- Updates Q-values as the agent gains experience.
- Uses Q-values to select the best action based on what it has learned.

**Key Takeaways**
- Model-free: Does not explicitly model T or R.
- Q-table: Stores the value of taking an action in a particular state.
- Goal: Find the optimal policy by choosing actions with the highest Q-values.

Important: Q-Learning is guaranteed to converge to an optimal policy under certain conditions. There is a limitation to this guarantee.

## 2. What is Q?

<img width="744" height="536" alt="image" src="https://github.com/user-attachments/assets/110d0c63-ae60-4e5b-a336-026327a6f963" />

### 2.1 What is the Q Function?
Q represents the value of taking action \(a\) in state \(s\).

It can be represented as a two-dimensional table (Q-table):
- Rows: States (S)
- Columns: Actions (A)
- Each cell: Q-value for a specific **state-action pair**.
  
  Q(s,a)
  
### 2.2 What does Q-value represent?

Q-value has two components:

`Q(s,a)=Immediate Reward + Discounted Future Rewards`

It considers both:
- Immediate reward from the current action.
- Expected future rewards from subsequent actions.

**Important**: Q-learning is not greedy based only on immediate rewards. It considers long-term rewards.

### 2.3. How to use the Q-table to choose an action?

The policy `pi(s)` determines which action to take in state `s`.

We select the action with the highest Q-value:

<img width="815" height="317" alt="image" src="https://github.com/user-attachments/assets/7876a4a6-ea49-482f-aa1a-2598d54099f9" />

The best action is Buy, because it has the highest Q-value (10).

### 2.4 Optimal Policy
After sufficient learning, Q-learning can converge to:

<img width="641" height="163" alt="image" src="https://github.com/user-attachments/assets/000eaaad-ef48-4089-b4e7-bf8541e8d782" />

Key Takeaways
- Q-value = Immediate reward + Discounted future rewards.
- Q-table stores values for every state-action pair.
- Policy selects the action with the highest Q-value.

## 3 Learning Procedure

<img width="1023" height="600" alt="image" src="https://github.com/user-attachments/assets/ce1e2923-7ec0-4639-b18e-f66fafbd7cfd" />

### 3.1 Big Picture: Training Loop

Q-Learning learns by repeatedly going through historical training data (e.g., stock market time-series data).

Training process:
1. Select training data (oldest to newest).
2. Observe the current state `s`.
3. Consult the policy/Q-table to select an action `a`.
4. Execute the action and observe:
   - New state   `s'`
   - Reward `r`
5. Use the experience tuple to update the Q-table.
6. Repeat until all training data is processed.
7. Backtest the policy to evaluate performance.
8. Repeat training if performance continues to improve.

### 3.2 What Is Convergence?
Convergence means the model's performance stops improving significantly after repeated training iterations.

- Initially, performance improves with each iteration.
- Eventually, performance levels off.
- At this point, the Q-Learner is considered converged.

## 4 Update Rule

The goal is to update the Q-table using new experience so the agent can make better decisions.

<img width="1035" height="485" alt="image" src="https://github.com/user-attachments/assets/6dd7e8de-6a73-41d9-abda-5b8d44d97034" />

### 4.1 The learning process
The agent interacts with the environment and collects an experience tuple:
\[
(s,a,s',r)
\]

- \(s\): Current state
- \(a\): Action taken
- \(s'\): New state
- \(r\): Immediate reward received

It uses this information to update the Q-value for the state-action pair \((s,a)\).

### 4.2 Q-Learning Update Formula 

<img width="483" height="68" alt="image" src="https://github.com/user-attachments/assets/512bd77a-cc57-4cce-8c05-fa6b907beca9" />

The formula combines two things:

A. Old estimate
\[
(1-\alpha)Q(s,a)
\]

The previous Q-value, weighted by \(1-\alpha\).

B. New estimate
\[
\alpha[r+\gamma\max_{a'}Q(s',a')]
\]

Immediate reward + discounted best future Q-value, weighted by \(\alpha\).

<img width="762" height="161" alt="image" src="https://github.com/user-attachments/assets/72e44cdf-e547-464c-8ce7-ddb0f50a9944" />

Learning rate (α):
- High α → Learn faster; give more weight to new information.
- Low α → Learn slower; preserve more of the old Q-value.
- Common example: α = 0.2.
  
Discount factor (γ):
- Low γ → Focus more on immediate rewards.
- High γ → Value future rewards more.
- γ = 1 → No discounting of future rewards.

### 4.3 What does the future reward component mean?
\[
\max_{a'}Q(s',a')
\]

After taking action \(a\), the agent reaches a new state \(s'\).

It looks at all possible next actions and selects the one with the highest Q-value.

In other words: What is the best future reward I could obtain from my new state?

## 5 Two finer points

Q-Learning needs to explore different states and actions to learn the best policy.

<img width="833" height="449" alt="image" src="https://github.com/user-attachments/assets/0796bd29-d17d-43ba-a2dd-8156678d9ba0" />

### 5.1 Why is exploration important?

If the agent always chooses the action with the highest current Q-value, it may miss better actions it hasn't tried yet.

Therefore, it needs to balance:
- Exploitation: Choose the action with the highest Q-value.
- Exploration: Randomly choose an action to discover other possibilities.

### 5.2 How does it work? (Random Action Selection)

Use two decisions:
1. Randomly decide whether to explore or exploit.
2. If exploring, randomly select one of the available actions.
3. Exploration Probability
A typical starting exploration probability is 0.3 (30%).
- Early training: Higher probability of random actions → More exploration.
- Later training: Gradually decrease the probability → More exploitation.
- End of training: Mostly choose the action with the highest Q-value.

**Key Takeaways**

<img width="767" height="149" alt="image" src="https://github.com/user-attachments/assets/c9cf97f7-9802-4f50-8bfe-abfbad19e519" />

Remember: Early learning = Explore more. Later learning = Exploit more.

This approach is commonly called ε-greedy (epsilon-greedy) action selection.

### 6.2 How does the trading process work?

The Q-Learner evaluates stock features (e.g., technical indicators) to determine the current state.

Based on the Q-table, it decides whether to:
- Buy and start holding the stock.
- Hold the stock for several days.
- Sell the stock.
- Remain out of the market until the next buying opportunity.

Most actions are expected to be Hold, with occasional Buy and Sell decisions.

### 6.3 Impact on Portfolio Value

The trading strategy produces a step-like portfolio value pattern:
1. Start with initial cash.
2. Buy stock → Portfolio value changes with stock price.
3. Hold → Continue holding the position.
4. Sell → Close the position and realize the gain or loss.
5. Repeat the process.

Overall logic:

Stock features → State → Q-Learning → Action (Buy/Sell/Hold) → Portfolio value changes.
