# 1. Overview

Reinforcement learners create policies that provide specific direction on which action to take.

# 2. The RL Problem
## 2.1. What is the RL problem?

Reinforcement Learning (RL) describes a learning problem, not a specific algorithm or solution. 

Just as linear regression is one method for solving a supervised regression problem, there are many algorithms that can solve a reinforcement learning problem.

The central idea of RL is:

**An agent learns how to make decisions by interacting with an environment and receiving rewards or penalties based on its actions.**

<img width="574" height="390" alt="image" src="https://github.com/user-attachments/assets/7229d27e-d43b-4e47-965e-f64330cca1d5" />

For example, imagine a robot learning how to navigate a room. It needs to:

1. Observe its surroundings.
2. Decide what action to take.
3. Perform the action.
4. Receive feedback (reward or penalty).
5. Observe the new situation and decide what to do next.

This process is called the Sense–Think–Act cycle.

## 2.2 The five key components of RL
<img width="791" height="300" alt="image" src="https://github.com/user-attachments/assets/4fe5fa9f-f448-4683-9a87-0e90e4e56c09" />

`Step 1: Observe the environment (State, s)`

The robot first observes its environment.

The information it receives is represented by the state (s).

For example:
- The robot is currently in front of a wall.
- There is an open path to the right.
- Its destination is straight ahead.
All this information helps describe the robot's current state.

`Step 2: Decide what to do (Policy, π)`

The robot needs a strategy to decide which action to take.

This strategy is called the policy (π).


For example:
- If there is a wall ahead, turn right.
- If the path is clear, move forward.
  
**The policy is essentially the robot's decision-making strategy**.

`Step 3: Take an action (a)`

Based on the policy, the robot performs an action.

Examples:
- Move forward.
- Turn left.
- Turn right.
- Stop.

The action can change the environment.

The question is **how do we arrive at this policy?** This whole puzzle is missing a piece and that's the thing that helps us find pi.
And part of that piece is called r which is the **reward**. 

`Step 4: Receive a reward (r)`

After taking an action, the robot receives feedback called a reward (r).

The reward tells the robot whether its behavior was desirable.

For example:
<img width="792" height="185" alt="image" src="https://github.com/user-attachments/assets/9de72940-df05-42d2-862e-9c9a2b3b65f0" />

The reward provides feedback that helps the robot learn which actions are beneficial.

**Important**: The goal of RL is not simply to maximize the reward from one action. It is to maximize the total accumulated reward over time.

`Step 5: Environment changes (Transition, T)`

After the robot takes an action, the environment transitions to a new state.

This process is described by the transition function (T).
<img width="721" height="175" alt="image" src="https://github.com/user-attachments/assets/3a41dcd2-29ca-47a9-a805-0deb06ade88e" />

For example:

The robot is facing a wall (current state), decides to turn right (action), and now faces an open path (new state).

In real-world problems, transitions may be stochastic, meaning the same action can sometimes lead to different outcomes.

## 2.3 How does the robot learn the best policy?

This is the most important question in reinforcement learning.

Initially, the robot may not know which actions are best. It needs to learn from its interactions with the environment.

Over time, it uses the information it collects, including:
- States it has encountered.
- Actions it has taken.
- Rewards it has received.
- Outcomes of its actions.
  
An RL algorithm uses this experience to improve the policy.

The ultimate objective is:

`Maximize cumulative reward over time`

For example, the robot should learn to reach its destination efficiently rather than repeatedly hitting walls or taking unnecessary steps.

The key distinction:
- The RL problem defines what needs to be solved.
- The RL algorithm describes how to solve it.
- The policy is the learned strategy used to select actions.

# 5. Markov decision problem

A Markov Decision Process (MDP) is a mathematical framework used to describe a reinforcement learning problem. It defines how an agent interacts with an environment, makes decisions, and receives rewards.

## 5.2 Objective: Find the optimal policy

The RL algorithm aims to find the optimal policy pi^*, which maximizes cumulative reward over time.

## 5.3 Two algorithms

When T and R are known, we can use:
- Policy Iteration: Evaluate and improve the policy repeatedly.
- Value Iteration: Update state values repeatedly to find the optimal policy.

**Important for this course**: T and R are generally unknown, so we need RL algorithms that learn through interaction with the environment.

Remember: MDP = S + A + T + R; RL aims to find the optimal policy pi^*

## 7.1  Three reward optimization strategies
<img width="783" height="144" alt="image" src="https://github.com/user-attachments/assets/a9d4cec7-d2cf-4280-8ef1-c47f449cb8ae" />
## 7.2  Discounted Reward (Most Important)
<img width="709" height="532" alt="image" src="https://github.com/user-attachments/assets/33fc24c0-565c-4fd2-b3a3-008899a6f093" />

**Key Takeaways**
- Infinite Horizon: Consider all future rewards.
- Finite Horizon: Consider rewards over a fixed number of steps.
- Discounted Reward: Future rewards are worth less than immediate rewards.
- Gamma (γ): Controls how much we value future rewards.
- Q-Learning: Uses discounted rewards to optimize long-term decisions.

**Remember: Higher γ = more focus on the future; lower γ = more focus on immediate rewards.**
